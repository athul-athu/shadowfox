# Chennai Super Kings - Official Website

This is the official website for Chennai Super Kings (CSK), one of the most successful teams in the Indian Premier League (IPL). The website provides comprehensive information about the team, players, matches, and fan engagement opportunities.

## Pages Overview

### 1. Home Page (index.html)
The landing page features:
- Team introduction and welcome message
- Next match details
- Latest news section
- Quick stats about CSK's achievements
- Quick links to other important sections

![Home Page Screenshot](screenshots/home.png)

### 2. Players Page (players.html)
Dedicated to showcasing:
- Current squad members
- Player profiles and statistics
- Team management

![Players Page Screenshot](screenshots/players.png)

### 3. News Page (news.html)
Keeps fans updated with:
- Latest team news
- Match reports
- Press releases
- Team announcements

![News Page Screenshot](screenshots/news.png)

### 4. Schedule Page (schedule.html)
Contains information about:
- Upcoming matches
- Match timings
- Venue details
- Previous results

![Schedule Page Screenshot](screenshots/schedule.png)

### 5. Statistics Page (statistics.html)
Provides detailed stats including:
- Team records
- Player achievements
- Season-wise performance
- Head-to-head records

![Statistics Page Screenshot](screenshots/statistics.png)

### 6. Fan Zone Page (fanzone.html)
Interactive section featuring:
- Fan polls
- Discussion forums
- Fan contests
- Social media integration

![Fan Zone Screenshot](screenshots/fanzone.png)

## Technologies Used
- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome Icons

## Setup Instructions
1. Clone this repository
2. Open the project in your preferred code editor
3. Launch index.html in a web browser to view the website

## Screenshots
To add screenshots:
1. Create a `screenshots` folder in the root directory
2. Take screenshots of each page
3. Save them in the screenshots folder with corresponding names (home.png, players.png, etc.)
4. The README will automatically display them once added
